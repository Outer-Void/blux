# BLUX Hook System v1: event reference

Generated from `contracts/hooks/v1/events.schema.json` (design: [ADR-0012](../adr/0012-hook-system.md)).
`before` events marked vetoable can be stopped by a hook holding `veto:<event>`. Mutable fields change only
in the stated direction, for a hook holding `mutate:<event>.<field>`. Sensitive fields are masked unless the hook
holds `read_sensitive:<event>`. All strings are secret-scrubbed.

## Using the bus (internal)
```python
from blux_runtime.hooks import HookBus, HookPolicy, HookResult, HookSource

bus = HookBus(policy=HookPolicy(), receipt_sink=receipts.append)
bus.register(
    "tool.before_execute",
    lambda e: HookResult.veto("read-only") if e.payload["side_effects"] == "write" else None,
    source=HookSource("builtin", "readonly"),
    permissions=["veto:tool.before_execute"],
    priority=500,
)
runtime = Runtime(registry, policy, hooks=bus)  # executor events
router = ModelRouter(routes, hooks=bus)  # model.* and credential.requested
```

## External subscribers (plugins, skills, MCP)
```python
from blux_runtime.hooks import ExternalSubscribers, SubprocessTransport, skill_manifest

bus = HookBus(
    policy=HookPolicy({"builtin:*": (...), "skill:guard": ("observe:tool.before_execute", "veto:tool.before_execute")})
)
ExternalSubscribers(bus).register(
    skill_manifest("guard", ["tool.before_execute"], ["veto:tool.before_execute"], timeout_ms=2000),
    SubprocessTransport("guard-skill --hook"),  # event JSON on stdin; verdict JSON on stdout
)
```
A subscriber answers `{"action": "ok"}`, `{"action": "veto", "reason": "..."}` or
`{"action": "mutate", "fields": {...}}`. Any other action, `allow` included, is rejected and reported as
`security.violation`.
